# IRZA LEARNING

Platform belajar mandiri TKA Fisika.

## Fitur
- Jalur belajar dan peta materi buku
- Materi dan kuis pemahaman
- Pembaca materi menggunakan fitur text-to-speech browser
- Kisi-kisi TKA Fisika Pusmendik
- Try Out dan drilling soal
- Penyimpanan progres pada browser melalui `localStorage`

## Deploy
Website ini menggunakan GitHub Pages melalui GitHub Actions. Setiap push ke branch `main` menjalankan pemeriksaan sintaks JavaScript dan deployment.

Target URL: https://irza131.github.io/irza/

## Catatan
Progres belajar disimpan di perangkat/browser masing-masing. Menghapus data situs atau menggunakan browser/perangkat lain dapat membuat progres lokal tidak tersedia.
